![demo](https://github.com/user-attachments/assets/b441aa60-9e66-48aa-853f-ba35e8723f30)# Procedural Lava Lamp Animation
Python-scripted procedural animation in Blender featuring physics-based lava lamp simulation with custom shader materials.

## Overview
Generates animated lava lamp visuals using Blender's Python API, combining physics simulation with custom shader nodes.

## Technical Highlights
- **Procedural Animation:** Python scripting for keyframe generation
- **Physics Simulation:** Blender's fluid/particle systems
- **Custom Shaders:** Node-based materials with subsurface scattering
- **Automation:** Scripted camera animation and lighting setup

## Implementation Details
- **Language:** Python (Blender API)
- **Tools:** Blender 3.x
- **Key Features:**
  - Automated sphere generation and physics setup
  - Procedural material creation via nodes
  - Render pipeline automation
  - Keyframe interpolation for organic motion

## Render Settings
- Engine: Cycles/Eevee
- Materials: Procedural glass + emission shaders
